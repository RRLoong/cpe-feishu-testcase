## 1. P0–P3 定义（正式约束）

单条飞书用例须落为 **P0 / P1 / P2 / P3 之一**。判级时 **先符合下表**；再用 §4 模块矩阵落到具体场景。冲突时 **本表优先**。


| 等级     | 定义               | 判定要点                             | 失败后果            | 执行要求                     |
| ------ | ---------------- | -------------------------------- | --------------- | ------------------------ |
| **P0** | 阻断测试或阻断交付        | 无法启动测试、无法完成发布或验收，或涉及安全、合规、不可恢复损失 | 版本不可测试或不可交付     | 每次构建、提测及冒烟测试均须执行；失败后立即阻断 |
| **P1** | 核心功能不可用，但不阻断整场测试 | 用户核心任务无法完成；场景属于高频主路径或关键异常        | 主功能受损，版本不得按计划验收 | 每次回归测试及发版测试均须执行          |
| **P2** | 重要功能受损，但不构成交付阻断  | 次要功能、组合场景、边界条件、一般兼容性及一般异常        | 用户体验下降，通常存在替代路径 | 纳入完整版本测试及专项测试            |
| **P3** | 低风险或低频场景         | 界面细节、文案、低频入口、极端边界及探索性验证          | 对交付影响可忽略        | 可在资源允许时抽测，**不得纳入门禁**     |


**性能 / 稳定性**（用「用例类型」列区分；当前飞书仅 `功能测试` **/** `兼容性测试`；分级须仍符合上表）：


| 策略表述               | 用例类型（飞书列） | 建议分级         |
| ------------------ | --------- | ------------ |
| 有线、无线吞吐性能          | 功能测试      | P1；回归 P2     |
| 开关机 200/500/1000 次 | 功能测试      | 首轮 P0（200 次） |
| 7×24 满载            | 功能测试      | P1           |
| OLT/终端/光模块兼容       | 兼容性测试     | P2           |




### 1.1 模块内拆分（对齐 §4）

策略/矩阵写 **「P0–P1」** 时，按 §1 判定要点落入单级：

- 无法开测/无法交付、默认 WAN/WiFi、注册拨号、**升级**、**安全/合规** → **P0**
- 用户核心任务/高频主路径/关键异常（访客除外的主业务扩展可按场景）→ **P1**
- 次要功能、组合/边界、一般兼容、未适配、可不重测 → **P2**
- 外观/噪音/文案/低频入口/按需专项 → **P3**

策略写 **「仅 P0」**（如 WEB-安全）→ 该子模块**全部 P0**。

## 2. 判级流程（Agent 必执行）

```
【模块】+ 场景描述
  → §1 表核对判定要点 / 失败后果 / 执行要求
  → §4 模块矩阵查对应列（落单级）
  → 未覆盖：附录 A 国际兜底（仍须符合 §1）
  → 写分级依据（策略:章节 | §4.x | §1判定要点摘要）
```

**禁止**：用户说「N 条 P0」即全标 P0；须符合 §1、§4。§4 与 §1 冲突时以 **§1** 为准。

### 2.1 与用户指令


| 用户说法                      | 行为                        |
| ------------------------- | ------------------------- |
| 未写分级                      | §2 全自动                    |
| `按测试策略` / `Router_Pon 模版` | 仅本文档                      |
| `生成 N 条 P0 <模块>`          | 仅 §4 该模块 **P0 列**；不足 N 说明 |
| `生成 N 条 <模块>`             | P0–P3 混合 + 分级统计           |
| `全部 P0`                   | 依据保留建议级；字段 4 可注「用户覆盖」     |




### 2.2 输出格式

**默认（飞书导入）**：

1. **分级统计**表（批量 ≥3 条）
2. **测试点矩阵**：**序号 | 标题摘要 | 分级 | 分级依据 | 标签 | 用例类型**
3. **CSV 导入表**：20 列表头与 [feishu-import-template.xlsx](feishu-import-template.xlsx) 一致（已移除 **执行步骤**、**[废弃]预期结果**）；所属目录固定 `CPE`；用例类型仅 `功能测试` / `兼容性测试`

矩阵列分级依据示例：

```text
P0 | 策略:WEB-WIFI-基本功能 | §4.2 | 加密/信道/模式
P0 | 策略:TR069-基本功能 | §4.4 | reboot/升级/核心 get·set
P1 | 策略:WEB-WIFI-扩展 | §4.2 | 访客WiFi
```

用户明确要求「Markdown / 分段 / 8 字段」时，可改输出 Markdown 逐条模板（见 [reference.md](reference.md)）。

## 4. 模块优先级矩阵

> 子模块与关注点对齐 [Router_Pon_测试范围模版.md](Router_Pon_测试范围模版.md)；落入 P0–P3 时必须符合 **§1**。模版未填策略时，沿用本节与附录 A（仍受 §1 约束）。



### 4.1 OLT管理（P0–P1）


| 子模块 | P0                            | P1                                  |
| --- | ----------------------------- | ----------------------------------- |
| 注册  | GPON 基本；认证/上报/授权；带/不带 VLAN 拨号 | 光参数完整采集（硬件定版后至少 1 次）；OLT 注册配置遍历     |
| 状态  | OLT 查看 ONT 状态（常规）             | 故障管理异常上报                            |
| 配置  | **每准出版本 OLT 升级 ONU**          | 重启、改配置、DBA、性能参数、安全、组播等遍历一次（无更新可不重测） |




### 4.2 本地 WEB管理（P0–P1）


| 子模块  | P0                                     | P1                                                                |
| ---- | -------------------------------------- | ----------------------------------------------------------------- |
| WAN  | 默认拨号（Bridge/DHCP/PPPoE 等主路径）；NAT；防火墙基本 | IPv6/Static；ALG/UPnP/DMZ/Virtual Server/DDNS；双 WAN / 多 WAN；网络链路备份 |
| LAN  | DHCP IPv4+IPv6 基本                      | 不同网段 IP；客户端隔离                                                     |
| WIFI | **基本功能**：加密/信道/模式/国家码/功率；协议一致性         | 访客/WDS/WPS/多SSID；WMM/黑白名单；MU-MIMO/OFDMA/MLO                       |
| MESH | 未适配 → **P2** 或跳过                       | 适配后：组网/同步/漫游/自愈等 P0–P1                                            |
| 系统   | **软件升级**；reboot/恢复出厂                   | 配置备份与恢复；登录账户修改                                                    |
| IGMP | 版本、一致性、Snooping、Proxy                  | 无线组播转单播                                                           |
| VoIP | 主被叫基本通话；注册状态/周期                        | 三方/转接/等待/保持等                                                      |
| 安全   | **全部 P0**（IP/MAC/端口过滤等）                | —                                                                 |




### 4.3 Skyway / APP


| 类型                                | 分级                   |
| --------------------------------- | -------------------- |
| Skyway：设备绑定、状态查询、配置下发、DFX（模版多为空时） | 主路径 **P1**；未填细节用附录 A |
| APP：绑定、控制、网络设置、WiFi 设置主路径         | **P1**（功能生效）         |
| APP：可配置参数合法遍历                     | **P1**               |
| APP：定时重启/重置/升级/时区等                | **P1**               |
| APP：游戏加速等增值                       | **P2**               |




### 4.4 TR069 / ACS（P0–P1）


| 子模块                  | P0                                                                                  | P1     |
| -------------------- | ----------------------------------------------------------------------------------- | ------ |
| 基本功能                 | reboot/restore；**升级**；核心 get·set（ManagementServer / WiFi / DeviceInfo / Hosts.Host） | —      |
| 事件码 / 认证             | Inform/上线、认证主路径（模版空则按默认路径）                                                          | —      |
| 网络配置                 | **Internet WAN** ACS 改拨号（PPPoE↔IPoE 等）                                              | 可选节点   |
| WLAN / VoIP / 其他模块参数 | —                                                                                   | 扩展参数遍历 |
| 故障诊断                 | —                                                                                   | **P1** |




### 4.5 稳定性


| 项                                       | 类型  | 分级                                   |
| --------------------------------------- | --- | ------------------------------------ |
| 整机开关机（关注网络/版本回退/WiFi/crash/配置；含不完全启动断电） | 可靠性 | 默认 **200 次 P0**；修复验收 500/1000 次仍按 P0 |
| OverALL 满载 7d                           | 可靠性 | **P1**                               |
| Veriwave（频繁关联去关联；带机量/泄漏）                | 可靠性 | 送样前至少 1 轮 **P1**；无底层驱动更新 **P2**      |




### 4.6 性能


| 项                                      | 类型  | 分级                                     |
| -------------------------------------- | --- | -------------------------------------- |
| WAN/LAN：RFC2544、峰值吞吐、不同拨号吞吐            | 性能  | 首发完整采集 **P1**；无底层/性能相关更新则回归基础拨号 **P2** |
| WiFi：峰值、Range/OTA、MLO/MU-MIMO/OFDMA 增益 | 性能  | 同上；无 WiFi 驱动更新可仅保基础峰值 **P2**           |




### 4.7 其它


| 章节                                  | 分级                   |
| ----------------------------------- | -------------------- |
| 4G/5G 拨号注册（制式/频段/Profile/驻网搜网/链路备份） | **P0–P1**（至少交叉遍历一次）  |
| 4G/5G 性能（与 WiFi 共存、制式吞吐/CA）         | **P1**；无相关更新可 **P2** |
| ALL in ONE 抗干扰等专项                   | **P3**（按专项文档）        |
| 兼容性（OLT / WiFi / 浏览器 / RJ45）        | **P2**               |
| 硬件：LED/按键/接口 link、开关机异常检查           | **P0–P1**            |
| 硬件：外观/噪音                            | **P3**               |
| 硬件：电源/总线信号/高低温/功耗/温升/WiFi 性能采集      | **P1–P2**（首发或硬件改版）   |
| 其它专项（按需补充）                          | **P3**               |
