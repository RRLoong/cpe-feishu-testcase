## 1. P0–P3 定义

策略按**模块**给出区间（如 P0–P1）；单条飞书用例须落为 **P0 / P1 / P2 / P3 之一**。


| 级别     | 定义                                       | 准出   |
| ------ | ---------------------------------------- | ---- |
| **P0** | 关键点**基本功能/默认路径**；**每准出版本必测**；**安全**子模块全部 | 阻断   |
| **P1** | **扩展/高级/新特性**；完整遍历一次；常规/功能生效             | 版本内修 |
| **P2** | 兼容性；不涉及底层更新可减量；边界/未适配                    | 计划   |
| **P3** | 其它专项按需；外观/噪音                             | 可选   |


**性能 / 稳定性**（用「用例类型」区分）：


| 策略表述               | 用例类型  | 建议分级         |
| ------------------ | ----- | ------------ |
| 有线、无线吞吐性能          | 性能测试  | P1；回归 P2     |
| 开关机 200/500/1000 次 | 可靠性测试 | 首轮 P0（200 次） |
| 7×24 满载            | 可靠性测试 | P1           |


### 1.1 模块内 P0 / P1 拆分

策略写 **「P0–P1」** 时：

- 关键点 **基本/默认/注册拨号/升级** → **P0**
- 关键点 **访客/多SSID/WDS/MLO…** → **P1**
- **遍历一次 / 常规 / 可不重测** → P1 或 P2
- **兼容性 / 按需专项** → P2 或 P3

策略写 **「仅 P0」**（如 WEB-安全）→ 该子模块**全部 P0**。

## 2. 判级流程（Agent 必执行）

```
【模块】+ 场景描述
  → §4 模块矩阵查 P0/P1 列
  → 未覆盖：§8 国际兜底
  → 写分级依据（策略:章节 | SR7D4VA§x.x）
```

**禁止**：用户说「N 条 P0」即全标 P0；须符合 §1、§4。

### 2.1 与用户指令


| 用户说法                   | 行为                        |
| ---------------------- | ------------------------- |
| 未写分级                   | §2 全自动                    |
| `按测试策略` / `SR7D4VA 策略` | 仅本文档                      |
| `生成 N 条 P0 <模块>`       | 仅 §4 该模块 **P0 列**；不足 N 说明 |
| `生成 N 条 <模块>`          | P0–P3 混合 + 分级统计           |
| `全部 P0`                | 依据保留建议级；字段 4 可注「用户覆盖」     |


### 2.2 输出格式

矩阵列：**序号 | 标题摘要 | 分级 | 分级依据 | 标签**

```text
P0 | 策略:WEB-WIFI-基本功能 | SR7D4VA§4.2 | 加密/信道/模式
P0 | 策略:TR069-ACS-WAN | SR7D4VA§4.4 | PPPoE↔IPoE
P1 | 策略:WEB-WIFI-扩展 | SR7D4VA§4.2 | 访客WiFi
```

批量 ≥3 条：文首 **分级统计** 表。

## 4. 模块优先级矩阵

### 4.1 OLT管理（P0–P1）


| 子模块 | P0                            | P1             |
| --- | ----------------------------- | -------------- |
| 注册  | GPON 基本；认证/上报/授权；带/不带 VLAN 拨号 | OLT 注册配置遍历     |
| 状态  | OLT 查看 ONT 状态                 | 故障管理异常上报       |
| 配置  | **每准出版本 OLT 升级 ONU**          | 重启、DBA、组播等遍历一次 |


### 4.2 本地 WEB管理（P0–P1）


| 子模块  | P0                             | P1                         |
| ---- | ------------------------------ | -------------------------- |
| WAN  | 默认拨号；NAT；防火墙基本                 | 双 WAN、IPv6、ALG/UPnP/DMZ 等  |
| LAN  | DHCP IPv4+IPv6 基本              | 网段、客户端隔离                   |
| WIFI | **基本功能**：加密/信道/模式/国家码/功率；协议一致性 | 访客/WDS/WPS/多SSID；MLO/OFDMA |
| MESH | 未适配 → P2 或跳过                   | 适配后 P0–P1                  |
| 系统   | **软件升级**；reboot/恢复出厂           | 配置备份；账户修改                  |
| IGMP | 版本、一致性、Snooping、Proxy          | 无线组播转单播                    |
| VoIP | 基本通话；注册状态                      | 三方/转接等                     |
| 安全   | **全部 P0**                      | —                          |


### 4.3 Skyway / APP（默认）


| 类型                | 分级  |
| ----------------- | --- |
| 绑定、控制、网络/WiFi 主路径 | P1  |
| 参数合法遍历            | P1  |
| 增值功能              | P2  |


### 4.4 TR069 / ACS（P0–P1）


| 子模块     | P0                                     | P1             |
| ------- | -------------------------------------- | -------------- |
| 基本功能    | reboot/restore；**升级**；核心 get·set       | 故障诊断           |
| 事件码/认证  | Inform/上线                              | —              |
| 网络（ACS） | **Internet WAN** ACS 改拨号（PPPoE↔IPoE 等） | 可选节点           |
| 其它      | —                                      | WLAN/VoIP 扩展参数 |


### 4.5 稳定性


| 项        | 类型  | 分级                      |
| -------- | --- | ----------------------- |
| 开关机      | 可靠性 | 200 次 P0；500/1000 验收 P0 |
| 满载 7d    | 可靠性 | P1                      |
| Veriwave | 可靠性 | P1；无驱动更新 P2             |


### 4.6 性能


| 项               | 类型  | 分级               |
| --------------- | --- | ---------------- |
| WAN/LAN/WiFi 吞吐 | 性能  | 首发 P1；无性能相关更新 P2 |


### 4.7 其它


| 章节       | 分级                 |
| -------- | ------------------ |
| 4G/5G 拨号 | P0/P1              |
| 兼容性      | **P2**             |
| 硬件基本/开关机 | P0/P1；外观/噪音 **P3** |
| 其它专项     | **P3**             |
