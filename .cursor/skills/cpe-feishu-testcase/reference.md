# 飞书用例字段参考

本文档**仅界定**飞书项目 8 个用例字段的含义、格式与填写要求。  
判级与模块矩阵见 [test-strategy.md](test-strategy.md)；场景示例见 [examples.md](examples.md)。

---

## 字段总览

| # | 飞书字段名 | 必填 | 说明 |
|---|------------|------|------|
| 1 | 关联项目 | 是 | 飞书空间中的**项目名称** |
| 2 | 用例名称/标题 | 是 | 团队标题格式，见 §2 |
| 3 | 用例类型 | 是 | 枚举见 §3 |
| 4 | 用例分级 | 是 | P0 / P1 / P2 / P3，见 §4 |
| 5 | 标签 | 是 | 项目/模块标签，见 §5 |
| 6 | 前置条件 | 是 | 环境、版本、拓扑、初始状态 |
| 7 | 测试步骤 | 是 | 编号、可执行、一步一操作 |
| 8 | 预期结果 | 是 | 可判定，与步骤对应 |

---

## 1. 关联项目

**含义**：用例归属的飞书项目（空间内项目全名）。

**不是**：

- 通用用例的产品型号（写在前置条件；标题**不写**型号段，见 §2）
- 项目标签缩写（写在字段 5；可选写入前置）

| 概念 | 填写位置 | 示例 |
|------|----------|------|
| 飞书关联项目 | **字段 1** | `xxx研发项目`（团队维护正式名） |
| 项目标签 | `字段 5` | `LLA` |
| 产品型号（通用） | 前置条件 | `EVO6022GP3`、`SR7D4VA` |
| 产品型号（客户定制/特型） | 标题可选段 + 前置条件 | 标题 `【EVO6022GP3】`（见 §2） |
| 目录定位 | 标题 `【Mxxx-Fxxx-Cxxx】` | `M002-F004-C001`（见 [cpe-mf-tree.md](cpe-mf-tree.md)） |

未确定时填 `TBD_FEISHU_PROJECT`，生成后由人工替换。

## 2. 用例名称/标题

**含义**：飞书中的用例标题，须可独立表达测什么。

**格式**（团队统一，默认）：

```text
【Mxxx-Fxxx-Cxxx】【<模块标签>】【<客户定制型号>】【P0|P1|P2|P3】【auto|manual】<功能描述>
```

其中 **【客户定制型号】** 为**可选段**：

- **写**：客户定制、或明确针对某特殊型号的用例（用户/需求点名型号时），如 `【EVO6022GP3】`
- **不写**：未指定型号、通用能力用例——**整段省略**，不要留空 `【】`

**示例**：

```text
# 通用（无型号段）
【M001-F001-C060】【WiFi】【P0】【auto】不同WiFi协议（2.4G和5G）下的网络连通性

# 客户定制 / 特型（有型号段）
【M010-F004-C001】【TR069】【EVO6022GP3】【P0】【auto】通过ACS将Internet WAN由默认PPPoE修改为IPoE
```

| 段 | 必填 | 要求 |
|----|------|------|
| `Mxxx-Fxxx-Cxxx` | 是 | 目录定位：`M`/`F` 见 [cpe-mf-tree.md](cpe-mf-tree.md)；`Cxxx` 为该 M+F 下用例序号（C001 起递增），**不是**目录层 |
| 模块标签 | 是 | 与功能域一致，如 `WiFi`、`DHCP`、`TR069`、`PON`（大小写与飞书现网习惯一致即可） |
| 客户定制型号 | 否 | 仅客户定制或特型用例；未提及指定型号则**忽略该字段**（不输出该对 `【】`） |
| 分级 | 是 | 与字段 4「用例分级」一致：`P0` / `P1` / `P2` / `P3` |
| `auto` / `manual` | 是 | 是否可自动化：可自动填 `auto`，否则 `manual` |
| 功能描述 | 是 | 完整中文句：场景/条件 + 验证点；一条用例一个核心测试点 |

**要求**：

- `Mxxx`/`Fxxx` 必须能在 [cpe-mf-tree.md](cpe-mf-tree.md) 中找到对应节点；新功能先补树再占号。
- 禁止空洞标题（如「测 WiFi」「DHCP 测试」）。
- 即使用了标题型号段，前置条件仍写 DUT 型号与版本；项目标签仍写字段 5。
- 生成时：用户未点名型号 → 通用格式；点名「仅 EVO6022GP3 / 客户定制」→ 插入型号段。

**旧格式**（仅兼容存量，新建勿用）：

```text
【<产品型号>】【<项目标签>】【<模块>】<功能描述>；
```

## 3. 用例类型

**含义**：飞书「用例类型」列；当前项目**仅允许**以下两种（不得使用其它枚举）：

| 值 | 适用 |
|----|------|
| **功能测试** | 业务功能、配置、协议、Web/CLI、安全、性能、可靠性、回归、冒烟等（默认） |
| **兼容性测试** | OLT/终端/浏览器/光模块/多厂商对接等兼容性场景 |

未说明时默认 **功能测试**。  
原策略中的性能/可靠性等场景仍按 [test-strategy.md](test-strategy.md) 判 **P0–P3**，但「用例类型」列填上表二选一。

## 4. 用例分级

**含义**：用例执行优先级 **P0 / P1 / P2 / P3**（四选一）。

| 级别 | 字段 4 填写 |
|------|-------------|
| P0 | `P0` |
| P1 | `P1` |
| P2 | `P2` |
| P3 | `P3` |

**如何取值**：由 [test-strategy.md](test-strategy.md) 自动判定。  
批量输出时可在矩阵增加 **分级依据** 列（非飞书必填，便于评审）。

可选：在字段 4 下增加引用块说明依据，例如：

```markdown
### 4. 用例分级
P1

> 分级依据：P1 | 策略:WEB-WIFI-扩展 | 访客 WiFi
```

## 5. 标签

**含义**：飞书用例标签，用于筛选与统计。

**规则**：

- **至少包含**项目缩写（如 `LLA`）。
- 可与标题中【模块】一致地增加模块标签（如 `WIFI`、`ACS`）。
- 多标签使用英文逗号，无空格：`LLA,WIFI`。

| 标签示例 | 说明 |
|----------|------|
| `LLA` | 项目缩写（常见必填） |
| `LLA,ACS` | 项目 + ACS/TR069 类 |
| `LLA,WIFI` | 项目 + 无线类 |

标题 `【ACS】` 与字段 5 是否重复由团队习惯决定；**默认**模块相关用例写 `LLA,<模块>`。

## 6. 前置条件

**含义**：执行步骤前必须满足的环境与状态。

**建议结构**（bullet 列表，无则写 N/A）：

| 项 | 说明 |
|----|------|
| DUT | 型号、硬件版本、**软件版本** |
| 初始状态 | 出厂默认 / 恢复出厂 / 已导入模板；写明关键默认（如默认 WAN 方式） |
| 拓扑 | 上联、LAN/Wi‑Fi 下挂（IP/账号用占位符） |
| 依赖 | 如需先上网、先上线网管等，一句话说明 |
| 工具/账号 | 测试环境专用占位，**禁止真实密码** |

---

## 7. 测试步骤

**含义**：可重复执行的操作序列。

**格式**：

- 使用阿拉伯数字编号：`1.` `2.` `3.`
- **一步一操作**；含必要数据、界面路径或操作对象（未知用 `TBD`）
- 需要分阶段时在步骤内用 **阶段一 / 阶段二** 小标题

**禁止**：一步内堆砌多个无关操作；只有结论没有操作。

---

## 8. 预期结果

**含义**：各步骤的通过判定标准。

**格式**：

- 与步骤 **编号一一对应**（推荐 `1.` 对 `1.`）
- 结果须 **可观测、可判定**（页面状态、指示灯、获 IP、ping、日志关键字等）
- 失败时需采集的信息可写在对应预期末条或前置中（占位符，不写真实路径/密码）

**禁止**：仅写「正常」「成功」而无判定条件。

---

## 字段与输出模板对照

Markdown 分段输出时 8 个字段名**不得修改**（仅用户要求「Markdown / 分段」时使用）：

```markdown
### 1. 关联项目
### 2. 用例名称/标题
### 3. 用例类型
### 4. 用例分级
### 5. 标签
### 6. 前置条件
### 7. 测试步骤
### 8. 预期结果
```

**默认交付**：飞书导入 CSV，见 §9。

## 9. 飞书导入列映射

表头以 [feishu-import-template.xlsx](feishu-import-template.xlsx) 为准（**20 列**，顺序固定）。

相对旧版飞书模板已移除废弃列：**执行步骤**、**[废弃]预期结果**。

```text
用例名称,所属目录,标签,描述,优先级,用例类型,测试用例类型,工作项id,前置条件,关联需求（系统字段）,用例分级,步骤,预期结果,自增数字,子分类,关联用例集,流程版本,WBS状态,关联项目,关联需求
```

### 8 字段 → 飞书列

| 8 字段（语义） | 飞书列名 | 填写规则 |
|----------------|----------|----------|
| 用例名称/标题 | **用例名称** | 团队标题格式 §2 |
| — | **所属目录** | 固定 `CPE` |
| 标签 | **标签** | §5，`LLA,WIFI` |
| 分级依据（评审） | **描述** | `P0 \| 策略:… \| §4.x` |
| 用例类型 | **用例类型** | `功能测试` 或 `兼容性测试` §3 |
| 用例分级 | **用例分级** | `P0` / `P1` / `P2` / `P3` |
| 前置条件 | **前置条件** | §6，多行编号或 bullet |
| 测试步骤 | **步骤** | §7 |
| 预期结果 | **预期结果** | §8 |
| 关联项目 | **关联项目** | §1 |

### 留空列（导入时保持空单元格）

优先级、测试用例类型、工作项id、关联需求（系统字段）、自增数字、子分类、关联用例集、流程版本、WBS状态、关联需求

### CSV 技术要求

- 编码：**UTF-8 带 BOM**（Excel / 飞书中文兼容）
- 表头：与模板 xlsx 第一行**完全一致**
- 多行单元格：双引号包裹，内部换行用 `\n`
- 保存路径：`testcases/<型号小写>/<模块>/feishu-import-<批次>.csv`

### 导入步骤

1. 飞书项目 → 用例 → **导入** → 选择生成的 `.csv` 或填入 [feishu-import-template.xlsx](feishu-import-template.xlsx) 后上传 `.xlsx`
2. **建议先导入 1 条**验证「步骤 / 预期结果」格式
3. 列映射以飞书导入向导为准

完整 CSV 样例见 [examples.md §7](examples.md#示例-7飞书导入-csv批量)。
